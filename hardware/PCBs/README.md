# This directory contains PCBs for TAFY
Some of these PCBs (such as the Mainboard) are not, strictly speaking, necessary to run TAFY. However, they do provide creature comforts and make cable management easier.
Other PCBs (the Motor Control PCB) are essential to safely run TAFY.

PCBs are designed in Fritzing. We recommend using Aisler for PCB fabrication, as you can take the Fritzing files and simply upload them. And, as they are in the EU, shipping for EU residents is cheaper. This being said, if you wish to use another service, such as JLCPCB or PCBWay, that is also valid. You will, however, need Fritzing to convert the Fritzing project files into Gerber files needed for fabrication with those services.
